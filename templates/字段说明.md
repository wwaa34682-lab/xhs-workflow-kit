# 资产表字段说明

所有表都是 CSV（UTF-8-BOM），放在 `data/tables/`。Excel、飞书多维表、WPS 都可以直接导入。`build_tables.py` 会校验这些表、补齐缺的列，并汇总成 `data/out/资产总表.xlsx`。
空表的表头在 `templates/tables/*.csv`，通用起步风格锁在 `templates/风格锁_通用起步.csv`。

## 1. 爆款样本库_样本帖子（一篇帖子一行）
各字段怎么写，以 `templates/拆解模板.md` 为准（A2 是对标，B2 是自有）。下面只说明列的用途。
- **通用**：样本ID（BM-### 对标 / OWN-## 自有，由 ingest 自动分配）、来源类型（对标 / 自有·<账号用途>）、账号或作者、标题（原文照抄，含 emoji）、行业、笔记ID（第 8 步关联投流必须用）、帖子链接、图片数、正文原文、标签、版权状态、采集方式（手动提供 / 专用小号自动）、采集日期、来源文件、修正说明、待核事项。
- **对标专用（模板 A0/A2）**：发布日期原样、日期解释、日期证据状态、筛选状态、正式合格（正式合格 / 候选）、评论核验口径、已核意向评论下限、已核不同用户下限、已取全图、文案记录方式、图序观察、设计结论、点击机制_推断、咨询解释、本品牌迁移、不可照搬、查看边界。
- **自有专用（模板 B2）**：整体风格、图组顺序、顺序判断、品牌一致性、建议、互动与日期（看到什么写什么，不补 0）。
- 不适用的列留空；还没填的列写【待拆解】。

## 2. 爆款样本库_样本图片（一张图一行）
- **通用**：图片ID（<样本ID>_Pxx）、样本ID、来源类型、图序、图片角色（首图 / 内页 / 尾图）、帖子链接、原图相对路径、图片来源URL、图片SHA256、宽px、高px、原图类型、已看实图、含AI内容、版权状态、待核事项。
- **对标专用（模板 A3）**：构图_观察、主体比例_目测外接框、字体层级_观察、配色_观察、文案卖点_观察、阅读顺序_推断、可取之处、局限、点击机制_推断、本品牌迁移建议、不可照搬、图示区域_近似归一坐标。
- **自有专用（模板 B3）**：构图、素材、字体形态、色彩、信息层级、品牌识别、主要优点、需要调整、具体改法。
- 比例是目测的，字体只描述形态（不猜字库），颜色用文字描述。含AI内容填“是”的图，不能当真实素材或证据用。

## 2a. 对标咨询证据（一条意向评论一行，模板 A4）
匿名编号（C###）、样本ID、资格（计入 / 不计入）、所属帖子、评论短证据（只写短句，不写用户名）、原有意向判断理由、原帖链接。

## 2b. 自有账号摘要（一个账号一行，模板 B1）
账号、账号ID、样本定位、稳定元素、保留、需要调整、优先动作、代表帖（样本ID）、报告日期、来源文件。

## 3. 风格锁（一条规则一行）
| 字段 | 说明 |
|---|---|
| 规则ID | SL-G** 是通用起步规则；SL-B** 是本品牌规则；SL-P** 是数据回收提出的提议；SL-AD-/SL-SIM-* 是复盘时写回的规则（真实 / 模拟） |
| 版本 | 每改一次加 0.1 |
| 维度 / 规则 / 必须做 / 禁止做 | 写到“拿着就能执行”的程度 |
| 依据来源 | 样本ID、评审回流ID、投放数据 |
| 状态 | `生效·…`（必须遵守）/ `提议·待专家确认`（不生效）/ `已否决` |
| 专家意见 / 更新日期 | 专家原话 |

## 4. 评审回流库（一条意见一行）
| 字段 | 说明 |
|---|---|
| 回流ID | RV-<稿件ID>-01… |
| 来源 | 专家评审 / 投放数据 / 投放数据·模拟 |
| 稿件ID / 评审轮次 / 评审人 / 评审日期 / 评分(1-10) | |
| 结论 | 通过 / 不通过 / 修改后再审；复盘时写“X 胜出” |
| 问题位置 / 问题类型 | P01 / 正文 / 标题……；排版、配色、照片、文案、事实、投流效果 |
| 专家原话 | **照抄** |
| 修改建议 / 回写目标 | 要改哪条规则（规则ID） |
| 是否已回写 / 回写后版本 | 是 / 否 / 不需要；改成了哪条规则的哪个版本 |

## 5. 发布队列（一个稿件或一个投流方案一行）
| 字段 | 说明 |
|---|---|
| 队列ID | PQ-001…；投流方案是 PQ-AB-<稿件ID> |
| 稿件ID / 账号 / 标题 / 稿件路径 / 图片数 / 版本或套系 | |
| 状态 | 待审 → 不通过 / 已通过，待发布 → 已发布 → 投流方案·待人工建计划 → 投流中 → 已复盘 |
| 评审轮次 / 专家结论 | 专家结论不是“通过”时，`ledger.py` 不允许把状态改成“已发布” |
| 含AI内容 | 是 / 否。填“是”的，发布时必须勾选「含AI生成内容」 |
| 计划发布时间 / 实际发布时间 / 笔记ID / 笔记链接 | 发布后回填 |
| 是否投流 / 关联投流计划 / 投流目标 | |
| 待确认事项 / 备注 | |

## 6. 投放效果库（聚光的一个计划一行，由 recover_juguang.py 生成，不要手改）
计划名称、创意名称、笔记ID、消费、展现量、点击量、点击率、平均点击成本、互动量、私信进线数、私信开口数、留资数、留资成本，
以及：关联样本ID、匹配方式（笔记ID / 计划命名 / 计划名≈标题 / 创意名≈标题 / 冲突 / 未匹配 / 排除 / 模拟替身）、置信度（高 / 中 / 待核 / 待补 / 模拟）、匹配依据、数据区间、数据来源、备注。

## 7. 投放映射（人工维护：计划 → 帖子）
计划名称、笔记ID、关联样本ID、匹配方式、置信度、依据、备注。第一次运行时自动生成，之后**只补不覆盖**：
- 在聚光后台查到笔记ID 后填进来，置信度改为“高”；
- 要排除的计划，匹配方式填“排除”。

## 8. 自然流量库（可选，创作者中心导出）
笔记ID、标题、关联样本ID、发布日期、曝光、观看、点赞、收藏、评论、分享、涨粉、数据区间、数据来源、备注。
