# 参考图拆解清单（第 5 步 · 选项 1「给参考图，做针对性修改」）

参考图由用户提供，至少 1 张，放在 `data/refs/<稿件ID>/`。参考图**只作参考**：不进成品、不商用原图、不抠用原图元素。
按下面 6 项逐张看图，写进 `config/layout.yaml` 的 `reference.breakdown`。写完再填 `kept`（保留了什么）和 `changed`（改了什么），然后把每一项落实到对应的 layout 参数。
六项和 kept / changed 都填完、参考图目录里有图，`render_post.py` 才会出图。

| # | 拆解项（breakdown 键） | 要看什么 | 落到 layout.yaml 的参数 |
|---|---|---|---|
| 1 | 版式 | 画幅比例；区块怎么分（上标题/中主体/下信息）；主体的位置和占比（目测外接框）；留白多少；有没有出血 | `canvas`，`cover.subject.center / radius`，`inner.photo_box` |
| 2 | 字体 | 标题、正文、数字各是什么**字形**（圆润 / 黑体 / 楷体 / 手写 / 倾斜）；粗细；描边和投影；字号层级的比例。不猜字库名 | `brand.fonts` 三款里选哪款对应哪层；`slots.*.font / size`；`styles.*.stroke_width / shadow` |
| 3 | 调色 | 底色（纯色 / 渐变 / 照片）；主色、辅色、强调色；冷暖对比；饱和度和明度；有没有滤镜或肌理 | `palette`，`cover.background`（type、top、bottom、texture），`variants` |
| 4 | 主体 | 主体是什么（巨物 / 产品 / 人物 / 照片拼贴）；质感；和背景怎么分开 | `cover.subject.type`（sphere / disc / image / none）、`pattern`、`painterly` |
| 5 | 装饰 | 涂鸦、贴纸、边框、箭头、编号、路线、纹理；线条风格；出现在哪个区域 | `doodles.items / zones / color`，`route.*`，`inner.frame` |
| 6 | 文字位置 | 每个文字块在哪里（大致 y 坐标）、怎么对齐、压在主体还是背景上；阅读顺序 | `cover.slots.*.y / align / x / style`（压在主体上一律用 on_subject） |
| 7 | kept 保留 | 一句话列出照搬参考图的结构和手法 | `reference.kept` |
| 8 | changed 改动 | 换成品牌色、品牌字体、本品牌主体、门店节点、已确认事实、用户自己的照片和文案 | `reference.changed` |

## 写法要求
- 先写观察，再写推断。比例是目测的，颜色用文字描述加近似色值，字体只描述形态。
- 有多张参考图时，写清楚每一项参考的是哪一张，比如「版式取 ref_01，调色取 ref_02」。
- 风格锁里已经生效的规则优先于参考图。冲突时按风格锁做，并写进 changed。

## 交付给用户时（按 docs/交互规范.md）
给用户看「参考图 | 我们的成品」对比，然后列：
- 保留了：……（3 条以内）
- 改成了：……（3 条以内）
- 问：哪里还要改？直接说位置和感觉就行，比如“标题再大一点”“颜色太艳”。

## 迭代
用户每提一条具体意见，就在 `reference.iterations` 里追加 `{round, feedback: 原话, change: 改了哪个参数}`，改参数重出，再给用户看对比。
不要一次大改，只改用户说的地方。
