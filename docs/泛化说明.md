# 从实战案例泛化了什么

这个工具包来自一个线下门店品牌在小红书上的完整一轮实战：从对标拆解到投流复盘。下面是哪些东西被保留成了通用机制，哪些被去掉了。

| 实战里的做法 | 工具包里的通用形式 |
|---|---|
| 固定的品牌名、门店、价格、色值、字体写死在脚本里 | 全部写进 `config/brand.yaml`，由 onboarding 问答填写；没确认的写【待业务确认】 |
| 针对某一张模板图写的一次性出图脚本 | `render_post.py` + `layout.yaml`：背景、主体（球体/圆/产品抠图）、涂鸦、门店路线、文字槽位和样式都写成参数；用 `variants` 出 A/B 套系 |
| 写死的品类主体（带凹坑的球） | `subject.type: sphere`，加 `pattern: dimples` 可选；也可以是 `disc`、`image`、`none` |
| 专家五条差评（很 low、像 PPT、像促销海报、太直白、不像小红书） | 通用起步风格锁 SL-G03–G06 |
| 球上的字看不清 → 用描边加投影，不用硬底卡片 | SL-G07，加上 layout 里的 `on_subject` / `emphasis` 样式 |
| 正文“卖点不突出、转化弱”→ 卖点前置，加评论关键词 | SL-G09、SL-G11，`check_copy.py` 检查关键词 |
| 价格露出对点击率、留资成本几乎没影响 | SL-G14（提议，低样本） |
| 真人出镜首图留资成本最低（n=1） | SL-G15（提议），A/B 方案默认带一版“真人出镜” |
| 只看留资成本，过门槛再判，0 留资止损 | SL-G13，`ab_test.py` 的判定逻辑 |
| 专业号自然流量几乎为 0 → 只看聚光 | `recover_juguang.py` 以聚光为主，`--organic` 可选 |
| 部分笔记由专家决定排除 | `投放映射.csv` 里把 匹配方式 填“排除” |
| 用历史计划扮演新帖的 B/C/D 版本，演练复盘 | `recover_juguang.py --sim --proxy …` + `ab_test.py verdict --sim` |
| AI 换脸后发布要标注 | `face_policy` + `face_swap.py`，发布队列有「含AI内容」列，`build_tables` 和 `ledger` 会提醒 |

**去掉的内容**：品牌名、门店名、价格、投放金额、笔记ID、照片、人物、账号名，以及任何登录信息。demo 里的数据全部是虚构的。

**阈值也都可以配置**：
- 排名最低消费：`juguang.min_spend_for_rank`，默认 100 元。
- CTR 判定最少展现：`juguang.min_impressions_for_ctr`，默认 1000。
- CPL 门槛（2×账户 CPL 或 3 个留资）、止损线（1×账户 CPL）：按每个账户自己的基线自动计算。
