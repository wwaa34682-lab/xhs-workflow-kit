# 出图预设（第 5 步）
先按参考图（`templates/参考图拆解清单.md`）挑最接近的一款，复制成 `config/layout.yaml`，再按拆解改颜色、字号和位置。`xhs.py quickstart` 会按行业自动推荐：
| 预设 | 适合 | 需要的素材 | 行业默认 |
|---|---|---|---|
| 极简大标题 | 没有好照片、要克制的行业 | 无 | 医疗、医美、金融、其他 |
| 产品主体 | 产品本身好看 | 产品抠图 `data/raw/product.png` | 餐饮、咖啡茶饮、零售 |
| 照片满版 | 人和空间就是卖点 | 自有实拍 `data/raw/cover.jpg` | 美业、健身、教育、本地生活 |
| 探索地图 | 参考图本身是“地图海报”风格，多门店 | 无（主体是程序画的圆形巨物） | 不默认，只在参考图匹配时用 |
每个预设的 `variants.B` 只改一个变量，可以直接拿来做 A/B。价格默认不放大（风格锁 SL-G14）。
