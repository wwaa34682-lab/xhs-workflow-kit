# 第 04 步 · 出文案（标题 / 正文 / 标签）

**目标**：写出一篇符合风格锁、只用已确认事实的小红书文案。

**输入**：`config/brand.yaml`、风格锁里状态为“生效”的规则、第 1 步对标帖的标题和正文结构。稿件目录为 `data/drafts/D001/`。

**先核对事实（一张确认卡）**：运行 `python scripts/xhs.py card --step 4`，把输出原样发给用户。卡上把这一步缺的事实（时长/份量、包含项、有效期、顾客顾虑、评论关键词、能说的话、不能说的词，受监管行业再加资质和合规审核人）一次列出。用户前面亲口说过的先填好（写在 `data/facts_draft.yaml`：`offer.0.duration: {value: "45分钟/节", source: "用户原话"}`），没说过的留空。用户回“对”或只改错的几条，你照抄写进 `brand.yaml`。不要逐条连问。

**再问用户一句**（可以和确认卡放在同一条消息末尾）：这篇是**转化帖**（目标是留资，卖点前置，见 SL-G09），还是**种草帖**（目标是收藏和互动，从生活方式切入，见 SL-G10）？答案写进 `pages.yaml` 的 `post_type`，第二篇默认沿用。

**给 agent 的提示词**
```
为稿件 D001 写 data/drafts/D001/copy.md，包含三部分：# 标题、# 正文、# 标签。
- 标题给 5 个备选，每个 ≤20 字，口语化，带反差或好奇心；不要用价格开头（SL-G14）。
- 正文严格按风格锁里生效的规则写。转化帖的结构：1–2 句钩子 → ✅ 卖点清单 → 3 行以内的体验细节 → 📍门店一行 → 评论关键词 CTA。
- 卖点清单里每一条都必须能在 config/brand.yaml 里找到原话；找不到的写【待业务确认】。
- 如果用了第一人称的体验故事，又不是真实用户的经历，结尾加上 content_rules.scenario_label。
  受监管行业（compliance.profile 是医疗、医美、教育、金融）**不能写第一人称体验故事，也不能用顾客或患者的口吻**，“情景演绎”标注在这里不算免责。要改用机构或专业人员的科普口吻，并带上合规包要求的免责语（比如“具体以医生面诊为准”）。
- 资质类说法（三甲、认证、进口、执业……）只能照抄 brand.yaml 的 qualifications；数量、规格、优惠（500ml、12 个座位、第二杯半价、免费……）都必须能在 offer 里找到。
- 受监管行业用机构口吻（“我们的课堂…”可以），不写效果承诺（“3个月开口”“效果看得见”“提分快”“学会30个单词”），不写没确认的紧迫感（“名额有限”“立即报名”）。
- 不带数字的服务承诺（“不办卡”“不推销”“无隐形消费”“一对一”“外教”）也是事实，没在 brand.yaml 里就不能写。
- 评论关键词确认后，把首图 pages.yaml 的 cta 补上（快速起步的首图不带 CTA）。
- 标签 5–10 个，组合方式：城市 + 品类 + 人群 + 场景。
写完运行 python scripts/check_copy.py --config config/brand.yaml --copy data/drafts/D001/copy.md，把“必须改”的问题全部改掉。
它会按行业合规包（config/compliance/）检查违禁词、违禁句式、必带免责语、资质出处，以及数字和单位、不带数字的优惠用语。“第一次、第一步”这类序数词不会被“第一”误拦。
受监管行业：发布前还要把文案交给 compliance.reviewer 过一遍，并记下来：ledger.py review --draft D001 --type 合规 --verdict 通过 --reviewer <审核人> --quote "原话"（没有这条，发布和投流会被拒绝）。
然后把标题、正文、标签原样发给用户确认。
```

**产出**：`data/drafts/D001/copy.md`，并在发布队列登记：`python scripts/ledger.py --data data --config config/brand.yaml queue --draft D001 --status 待审 --title "<暂定标题>" --path drafts/D001/`。

**人工关卡**：用户挑定标题，确认正文和标签。用户说“卖点不突出”“太直白”这类意见时，在第 6 步记成评审回流。

**完成标准**：`check_copy.py` 返回 0；用户确认了标题、正文和标签（原话写进 `pages.yaml` 的 `copy_confirmed`，`xhs.py status` 靠它判断）。
