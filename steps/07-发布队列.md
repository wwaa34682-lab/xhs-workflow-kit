# 第 07 步 · 发布队列 → 用户自己发布【人工关卡】

**目标**：把定稿交给用户发布，并登记发布信息，供第 8 步关联数据用。

**给 agent 的提示词**
```
1. 确认发布队列里 D001 的专家结论是“通过”。如果不是，回到第 6 步。
2. 把 out/P01…Pnn.png 和定稿文案（标题、正文、标签，纯文本可以直接复制）打包给用户，发布前提醒用户检查：
   - 含AI内容=是 时，勾选「含AI生成内容」；
   - 正文里有情景演绎标注时，不要删；
   - 图上的评论关键词要和正文一致。
3. 用户发布后，请他把笔记链接或笔记ID 发过来，然后登记：
   python scripts/ledger.py --data data --config config/brand.yaml queue --draft D001 --status 已发布 --note-id <笔记ID> --link <链接>
```

**产出**：发布队列里 D001 的状态变为“已发布”，并带有笔记ID。

**人工关卡**：发布由用户本人操作。agent 不登录、不代发。

**完成标准**：笔记ID 已回填。第 8 步就靠它把投流计划关联到这篇稿件。
