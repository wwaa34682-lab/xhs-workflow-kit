# 第 02 步 · 自有帖收集 → 入库 → 拆解

**目标**：拆解本品牌过去的帖子，找出强项和老毛病，同时为第 8 步关联投流数据打基础（标题、笔记ID 要准）。
**拆解一律按 `templates/拆解模板.md` 的 B 部分**（用户自己的“账号视觉复盘”结构：摘要 · 账号观察与优先动作 / 逐帖小结 / 逐图详解）。填写示例见 `templates/拆解模板_填写示例.md`。

## 收集（和第 1 步一样有两种模式，收件箱换成 `data/inbox/own/`）
- **模式 A 手动提供**：用户给自有帖的截图或原图、标题、正文，以及创作者中心能看到的互动数。
  在 metrics.txt 里写「备注: <账号用途>」，比如“转化号”，入库后来源类型就是“自有·转化号”。
- **模式 B 专用小号**：用同一个研究小号打开**本品牌账号的公开主页**，逐篇保存。规则和节奏与第 1 步完全一样。
  **不要为了采集去登录品牌主运营账号**。用户要提供后台数据（比如笔记ID、私密数据），请他从创作者中心自己导出。
- 已经有现成的拆解报告（PDF 或表格）时，可以直接按模板 B 的字段把内容搬进表里，不用重新拆。

## 给 agent 的提示词
```
1. 运行 python scripts/ingest_posts.py --data data，自有帖会建成 OWN-** 的空壳行。
2. 每个账号先写一行「自有账号摘要」（模板 B1）：样本定位、稳定元素、保留、需要调整、优先动作、代表帖。
3. 每篇帖子按模板 B2 填：整体风格、图组顺序、顺序判断、品牌一致性、建议、互动与日期。
   标题照抄原文（含 emoji）。笔记ID 一定要填，第 8 步靠它关联投流数据。
4. 每张图按模板 B3 填：构图、素材、字体形态、色彩、信息层级、品牌识别、主要优点、需要调整、具体改法。
   素材里如果写了含 AI 生成内容，「含AI内容」填“是”，以后不能把它当真实素材或证据用。
5. 一篇帖子被拆成几段的要合并；重复的字段去重；改动写进「修正说明」。
6. 填表用 python scripts/fill_breakdown.py（template → 填好 → apply），不要手改宽 CSV。
7. 运行 python scripts/build_tables.py --data data --config config/brand.yaml，直到没有【待拆解】。
最后对照对标帖，列出“我们比对标差在哪” 3–5 条，作为第 3 步的候选规则。
```

**产出**：`OWN-*` 的帖子行和图片行，以及「自有账号摘要」。

**给用户看什么（减负）**：只给账号摘要（B1）和 3–5 条差距清单，逐图明细不主动展示。

**用户过目（不是关卡，不停下来等）**：把拆解摘要给用户看，顺带说“有看错的地方（比如合并的帖子、字体和色彩）直接告诉我”，然后自动往下走。

**完成标准**：模板 B 的三层（账号 → 帖子 → 图片）都填完；能拿到的笔记ID 都已填写；差距清单已经交给用户。
